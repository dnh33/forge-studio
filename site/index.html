the forge is not idle

A free, public image pipeline that renders on GitHub's own runners, and a grimdark desktop studio to drive it: write prompt sets, dispatch the run, watch it live, preview the output, take the download.

Download the studio The pipeline Source

How a run works

PlanEvery job is resolved: prompt text, canvas, seed, steps. One-off prompts run without ever being committed.
RenderShards render in parallel on free public runners. A small open model, CPU only, no API keys.
PublishArtifacts land on the renders branch with a JSON sidecar per image and rebuilt contact sheets.
PreviewThe studio watches the run through the GitHub API and offers the images the moment they exist.

Why it is free

Public runners

GitHub-hosted runners cost nothing for public repositories. The pipeline trades time for money: the batch is where the pipeline wins, and a GPU is where it is fast.

Open weights

An Apache-2.0 image model and an MIT runtime. Nothing to buy, nothing to license, nothing to leak.

Sharding

Split the batch across jobs. Each downloads the model once, so wall-clock time falls with every shard you add.

Your key stays yours

Ideation uses OpenRouter, but the key never lives in the app's window, never in a file, never in a log. It goes straight into the Rust core and the OS credential store — or set OPENROUTER_API_KEY in the environment and the UI never sees it at all.

Build it yourself

git clone https://github.com/dnh33/forge-studio
cd forge-studio/app
npm install
npm run tauri build

No local toolchain is required: every tag builds the installers on GitHub's runners and attaches them to a draft release, which is verified before it goes live.
